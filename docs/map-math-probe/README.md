# 地图坐标与手势验证页

一个不依赖任何框架的单页实现，用来在动手写安卓代码前验证两件最容易出错的事：

1. 归一化坐标 → 屏幕位置的换算是否与 iOS 版一致（适配矩形、居中偏移）
2. 缩放/平移/点位拖拽的手势仲裁是否顺手（开发者模式下单指拖点、双指平移）

数据与 `app/src/main/assets/lineups_mirage.json` 保持同构，改动其一即可对照。

## 怎么打开

在电脑上直接双击 `index.html`，或把整个目录拷到手机后用浏览器打开。

## 已验证结论

- 适配矩形计算与 iOS 版完全一致：图片 1206×1214 放进任意容器，得到居中矩形后再映射点位，点位落点准确
- 现有 3 组点位的坐标与雷达图自身的标注不符，属于占位数据，需要在开发者模式里逐个校正
